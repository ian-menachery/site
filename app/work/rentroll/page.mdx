# rentroll

Checks that the numbers pulled from a property's rent roll and operating statement tie out, and points at the rows that don't.

Private repository · [Try the checker on synthetic data](/lab/rentroll) · Python, Pydantic, MCP · September 2026

## The question

Pulling numbers out of a multifamily rent roll and T12 is largely solved. Knowing whether those numbers tie out is not. Does the unit count match, does gross potential rent add up, do the twelve months sum to the annual total, and does NOI recompute?

## Approach

There are five checks. Each is a pure function that takes the deal documents and tolerances and returns pass, fail or skip, with references to the offending rows.

| Check | Rule |
|---|---|
| Unit count | unit rows match the stated total exactly |
| Gross potential rent | in-place rent for occupied units plus market rent for vacant ones, within 0.5% of the stated figure |
| Occupancy consistency | no occupied unit at $0 rent, no vacant unit carrying rent |
| T12 column sums | the 12 monthly values match each line's annual total, within $1 |
| NOI recompute | effective gross income minus operating expenses matches stated NOI, within $1 |

I cut a sixth check (rent roll against T12) because it needed judgment, and kept every remaining check mechanical. The checker runs as a command-line tool and as an MCP server that an AI assistant can call. The pass bars were set in advance, inside a 14-hour time box.

## Results

The first gate passed. On fixtures with injected errors, the rent check caught a rent variance and the occupancy check caught a misclassified vacancy, each naming the injected unit first, and the clean fixture produced zero false failures.

## What was hard

Gross potential rent needed the right basis: vacant units have to count at market rent, or the check fails on every clean rent roll. Empty input has to skip instead of reporting a −100% failure, and the NOI check skips when an expense category is absent. Each stated total is tagged as detected, overridden or absent, so a check never compares against a number nobody provided.

## Status

The gates against real deal packages haven't run yet, and the checker covers multifamily only. The code is private; the demo runs the same checks on synthetic data.
